# Papers without a fulltext file in `papers/people/` or `papers/methods/`

Papers cited in [`PAPERS.md`](../PAPERS.md) for which we have no PDF, ordered by expected usefulness for
the VZP challenge (interventions and experiment design first, then model, methods and economics).
DOIs and metadata were checked against Crossref and Europe PMC (10/2026). Papers found later through
OpenAlex, Semantic Scholar, arXiv and preprint servers were downloaded and removed from this list. Web pages and data sources
(Community Guide, VZP, ÚZIS and similar) are not listed; they have no paper to download.

**6 papers have free fulltext** (column *Free fulltext*): they are open access in PubMed Central or on
arXiv, only the automated download was blocked. They can be saved from a normal browser into `papers/people/` or `papers/methods/` (by the part of `PAPERS.md` the key belongs to)
as `<KEY>.pdf`. The rest are paywalled: library access or a request to the authors.
